# Microsoft Fabric Lab – Analyze Data in a Data Warehouse

## 🧪 Lab Overview
This lab explores how to build and analyze a relational data warehouse using **Microsoft Fabric**.

## 🚀 What I Did
- Created a workspace with Fabric capacity
- Built a data warehouse with four core tables:
  - `DimProduct`
  - `DimCustomer`
  - `DimDate`
  - `FactSalesOrder`
- Inserted data via SQL scripts
- Created relationships between fact and dimension tables
- Queried the warehouse using:
  - Standard SQL joins and aggregations
  - A visual query editor (Power Query style)
- Created and used a **view** (`vSalesByRegion`)
- Designed a **Power BI report** based on warehouse data

## 📊 Power BI Report
- Visualized total sales by product category
- Customized chart type and titles
- Saved and published the report in the Fabric workspace

## 🔧 Tools & Skills Used
- Microsoft Fabric
- T-SQL
- Data modeling
- Visual query editor
- Power BI report builder

## 📁 Workspace Artifacts
- Data warehouse
- Semantic model
- Sales report

## 🧹 Clean Up
All resources were organized in the workspace and can be deleted as needed after completion.
